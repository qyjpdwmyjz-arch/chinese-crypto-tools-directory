# Chinese Crypto Tools Directory

面向中文用户、持续维护的加密工具与安全资源清单。内容侧重工具用途、官方入口和风险提示，不提供投资建议。

完整的分类说明、教程与安全指南：[CoinAtlasNav](https://www.coinatlasnav.com/)

## 使用原则

- 核对官方网站域名、证书和公开安全记录。
- 不向任何人透露私钥、助记词、验证码或资金密码。
- 首次转账或链上交互使用小额资金测试。
- 连接陌生网站前检查授权内容，完成后取消不需要的授权。
- 遵守所在地法律法规，自行确认服务可用性。

## 安全检查清单

1. 从项目公开渠道交叉核对域名。
2. 不从私信、群聊或搜索广告直接下载钱包软件。
3. 签名前阅读交易模拟和授权对象。
4. 定期检查并取消不再使用的授权。
5. 为重要账户启用验证器和提现白名单。
6. 对助记词进行离线备份，不截图、不上传网盘。

## 收录标准

- 有可核验的官方网站和公开资料。
- 不使用夸大收益或保本表述。
- 重大安全争议必须明确记录。
- 提交者与项目存在商业关系时应主动披露。
